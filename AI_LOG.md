## Ход работы

1. **Постановка.** Загружен файл с ТЗ («сервис форм»), запрос: «сделай задание в файле».
2. **Выбор подхода** (исходя из жёстких требований сдачи):
   - запуск строго `npm install` + `npm start`, Node 20+, без внешних зависимостей → зависимостей нет вообще, хранилище — JSON-файл (SQLite потребовал бы нативной сборки или Node 22+);
   - MVP-сценарий из ТЗ (конструктор → ссылка → заполнение → ответы) реализован целиком;
   - из описанных в ТЗ проблем выбрана главная идея сверх MVP — аналитика уходов с формы по вопросам (проблема: «причина низкой конверсии остаётся неизвестной»).
3. **Реализация.** Сервер (`server.js`), клиент админки и публичной формы (`public/`), стили, README.
4. **Проверка.** Автотест `test/smoke.test.js` проходит весь сценарий: создание и валидация формы, публикация, недоступность черновика, отправка корректных и некорректных ответов, аналитика, CSV, редактирование формы со старыми ответами, сохранение данных после перезапуска, удаление. Отдельно сервер запущен командой `npm start` с `PORT`, проверены страницы и защита статики от выхода за пределы `public/`.

## Ограничения проверки
Интерфейс (`admin.js`, `form.js`) проверен на синтаксис и через API, но не прокликан в реальном браузере. Перед сдачей стоит пройти сценарий вручную: создать форму → опубликовать → открыть ссылку в другой вкладке → отправить → посмотреть ответы и аналитику.
